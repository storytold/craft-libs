# Support

Use GitHub Issues for reproducible defects, compiler errors, breaking changes, and bounded shared library proposals.

## Reporting issues

When reporting an issue, provide:
- Affected crate and exact version or Git revision;
- Operating system, Rust toolchain version (`rustc --version`), and target architecture;
- Complete, un-truncated terminal output or stack trace;
- Minimal reproduction test case or command (e.g. `cargo test -p <crate>`);
- The weakest claim tier supported by current evidence (Documented vs. Tested vs. Empirically Validated).

Questions specific to downstream application behavior belong in the respective application repositories rather than `craft-libs`.

Issue descriptions and feature requests must describe functionality and domain requirements without referencing proprietary commercial products outside the ArtCraft and Storytold ecosystem.
